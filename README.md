### 🛠️ O que eu faço

- **Automações com n8n**: captação de demandas, CRMs, assinatura de contratos, relatórios diários e filas com RabbitMQ.
- **Integrações com WhatsApp**: APIs multi-sessão em Go, webhooks, disparos com controle anti-ban e atendimento com agentes de IA.
- **Produtos web**: painéis, CRMs e plataformas em Next.js, TypeScript e Supabase.
- **IA aplicada**: agentes com base de conhecimento (RAG), classificação e resumo de mensagens.
- **Infraestrutura própria**: VPS com Docker, Traefik, deploy contínuo via GitHub Actions e GHCR.
